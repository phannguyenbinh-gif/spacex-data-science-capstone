# Push to GitHub

## Option A - GitHub website
1. Create a new repository, for example `spacex-data-science-capstone`.
2. Choose **Add file > Upload files**.
3. Upload the contents of this project folder.
4. Commit the files.
5. Copy the repository URL.
6. Put that URL into the final PDF title slide before final submission.

## Option B - Git command line

```bash
git init
git add .
git commit -m "Add SpaceX Data Science Capstone project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/spacex-data-science-capstone.git
git push -u origin main
```
